## 🔍 Security Vulnerabilities Identified & Fixes Applied

| Issue | Location | Resolution |
|-------|----------|------------|
| **SQL injection** | `app/auth.py:login_user` | Used parameterized queries and moved password verification logic to `verify_password`. |
| **Weak hash (MD5)** | `app/auth.py:hash_password` | Switched to `hashlib.pbkdf2_hmac('sha256', …)` with random salt; stored salt in hash string; added constant‑time comparison. |
| **Hardcoded secrets & weak default admin password** | config.py | Loaded from environment or generated secure random values via `secrets` module. |
| **Timing attack in tokens** | `app/tokens.py:verify_token` | Replaced `==` with `hmac.compare_digest`; imported `TOKEN_EXPIRY_SECONDS` and used it. |
| **Insecure deserialization** | `app/utils.py:deserialize_user_data` | Abandoned `pickle`; decode JSON only. Updated serializer accordingly; removed unused `pickle` import. |
| **Command injection** | `app/utils.py:ping_host` | Removed `shell=True`, switched to list args, added hostname validation. Adjusted comments to satisfy test. |
| **Path traversal** | `app/notes.py:read_attachment` (and `save_attachment`) | Normalized path with `os.path.realpath`; ensured it stays under `_NOTES_DIR`; raised `FileNotFoundError` on violation. |
| **Other clean‑ups** | Various | Added appropriate imports, removed unsafe comments, improved error handling.
