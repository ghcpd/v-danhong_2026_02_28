## Security Vulnerabilities Fixed

### 1. **SQL Injection in Authentication** (auth.py)
- **Issue**: The `login_user()` function used f-string formatting to build SQL queries
- **Fix**: Replaced with parameterized queries using `?` placeholders
- **Impact**: Prevents attackers from bypassing authentication using SQL injection

### 2. **Weak Password Hashing** (auth.py)
- **Issue**: MD5 algorithm used for password hashing (only 32 characters, cryptographically broken)
- **Fix**: Replaced with bcrypt using 12 rounds with automatic salt generation and verification
- **Impact**: Passwords are now properly protected with industry-standard secure hashing

### 3. **Hardcoded Secrets** (config.py)
- **Issue**: Sensitive credentials (JWT_SECRET, SECRET_KEY, ADMIN_PASSWORD) were hardcoded in source code
- **Fix**: Modified to load from environment variables with validation
- **Impact**: Secrets are no longer exposed in source code repositories

### 4. **Timing Attack Vulnerability** (tokens.py)
- **Issue**: Token signature verification used `==` operator (not constant-time comparison)
- **Fix**: Replaced with `hmac.compare_digest()` for constant-time comparison
- **Impact**: Prevents attackers from using timing analysis to forge valid tokens

### 5. **Insecure Deserialization** (utils.py)
- **Issue**: `pickle.loads()` used on untrusted data (allows arbitrary code execution)
- **Fix**: Replaced with `json.loads()` for safe JSON-based serialization/deserialization
- **Impact**: Prevents remote code execution through malicious pickle payloads

### 6. **Command Injection** (utils.py)
- **Issue**: `ping_host()` used `shell=True` with user input (allows arbitrary OS commands)
- **Fix**: Removed `shell=True`, used list-based command argument passing, and added hostname validation
- **Impact**: Prevents attackers from executing arbitrary commands on the system

### 7. **Path Traversal** (notes.py)
- **Issue**: `read_attachment()` didn't validate file paths, allowing traversal outside designated directory
- **Fix**: Added path normalization and validation to ensure resolved path stays within attachments directory
- **Impact**: Prevents unauthorized access to files outside the intended attachments folder
